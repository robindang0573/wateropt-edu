NPV — Giá trị hiện tại ròng

$$NPV = \sum_{t=0}^{n} \frac{B_t - C_t}{(1+i)^t}$$

Tổng tất cả dòng tiền đã quy về năm 0. NPV > 0 nghĩa là lợi ích vượt chi phí sau khi tính trượt giá theo thời gian.

Kết quả: {{ '{:,.2f}'.format(result.npv) }} triệu USD

B/C — Tỉ số Lợi ích / Chi phí

$$B/C = \frac{\sum B_t/(1+i)^t}{\sum C_t/(1+i)^t}$$

Mỗi 1 đồng bỏ ra thu về bao nhiêu đồng lợi ích. B/C > 1 là đang "lời".

Giá trị hiện tại lợi ích: {{ '{:,.2f}'.format(result.pw_b) }} ; chi phí: {{ '{:,.2f}'.format(result.pw_c) }} → B/C = {{ '{:,.2f}'.format(result.bc) if result.bc is not none else '—' }}

IRR — Tỉ suất hoàn vốn nội bộ

$$Tìm\ r\, : \quad NPV(r) = 0$$

Mức chiết khấu khiến dòng tiền vừa "huề vốn". Dự án tốt nếu IRR > tỉ suất chiết khấu yêu cầu ({{ '{:,.0f}%'.format(result.i) }}).

IRR = {{ '{:.2f}%'.format(result.irr*100) if result.irr is not none else 'Không xác định (NPV < 0 với mọi i)' }}

AW — Giá trị niên kim đều

$$AW = NPV \times \frac{i(1+i)^n}{(1+i)^n - 1}$$

Chia đều NPV ra thành 1 khoản bằng nhau mỗi năm trong n năm — dễ so sánh các phương án có tuổi thọ khác nhau.

AW = {{ '{:,.2f}'.format(result.aw) }} triệu USD/năm
